📋 SERVER SETUP (Ubuntu)
══════════════════════════════════════════════════════════════

1. Configure Remote Access:
   $ sudo ./scripts/configure-remote.sh
   
   → Detects server IP (e.g., 192.168.1.100)
   → Creates .env configuration
   → Opens firewall ports

2. Deploy Services:
   $ sudo docker compose down
   $ sudo docker compose up -d
   $ sudo ./scripts/init-vault.sh
   $ sudo ./scripts/init-keycloak.sh

3. Get Server IP:
   $ hostname -I
   → Example output: 192.168.1.100

🔥 FIREWALL PORTS (Required)
══════════════════════════════════════════════════════════════

Open these ports on Ubuntu server:

$ sudo ufw allow 3000/tcp   # Frontend
$ sudo ufw allow 5000/tcp   # Backend API
$ sudo ufw allow 8080/tcp   # Keycloak
$ sudo ufw allow 8200/tcp   # Vault
$ sudo ufw allow 51820/udp  # WireGuard
$ sudo ufw reload

⚠️ TROUBLESHOOTING
══════════════════════════════════════════════════════════════

Problem: Cannot access from client
Solution: 
  1. Check firewall: sudo ufw status
  2. Check services: docker compose ps
  3. Check ports: sudo netstat -tulpn | grep -E '(3000|5000|8080)'

Problem: CORS errors
Solution: Reinitialize Keycloak
  $ sudo ./scripts/init-keycloak.sh

Problem: Keycloak redirect issues
Solution: Check .env has correct SERVER_IP
  $ cat .env | grep SERVER_IP
